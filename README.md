# historymap — 地図で世界史を理解するツール

時間スライダーで世界地図を動かし、**ある時点に世界の各地で何が起きていたか（いつ・どこ）の横断面**を掴むためのツール。
出来事・国・民族・人物・時代区分を地図上に「点」でプロットし、各点はWikipediaへの入口になる。

「重要度・取捨選択は人間が、要約・抜け漏れチェック・リンクはAIが」という役割分担を前提に設計している。

🔗 https://github.com/goodsun/historymap

---

## 使い方（起動）

ブラウザは `file://` から直接CSVを読めないため、簡易サーバ経由で開く。

```sh
cd historymap
python3 -m http.server 8000
```

- 地図ビュー： http://localhost:8000/ （`index.html`）
- 表ビュー　： http://localhost:8000/table.html

依存は CDN の [Leaflet](https://github.com/Leaflet/Leaflet) のみ（地図タイルはオンライン前提）。ビルド不要。

## 画面と操作

### 地図ビュー（index.html）
- **時間スライダー**：BC6500〜2020。刻みは年代で可変（先史=1000年 / 古代=10年 / 中世以降=1年）なので、先史はサクサク・近現代は精密。
- **レイヤー**：`出来事 / 国 / 民族・部族 / 人物 / 時代区分` をチェックで切替。**ONにされたファイルだけを遅延ロード**。
- **分類**：`政治 / 戦争 / 宗教 / 思想・科学 / 技術 / 経済 / 文化 / 文明・国家 / 時代区分` でフィルタ。
- **表示幅 ±N年**：点イベントを前後どれだけ拾うか（既定±10年）。スパン（戦争・王朝など）は期間で判定。
- **マーカー**：マウスオーバーでバルーン表示。クリックすると右パネルの該当項目をハイライト（絞り込まないので他地域と比較できる）。
- 右パネルは種別ごとに「この時代の出来事 / 国 / 民族・部族 / 人物 / 時代区分」と並ぶ。各タイトルはWikipediaへのリンク。

| 操作 | 動作 |
|---|---|
| `←` / `→` | 1ノッチ移動（その年代の刻み幅） |
| `Shift` + `←/→` | 10ノッチ移動 |
| ▶ 再生 | 時間を自動送り |

レイヤー/分類のON/OFF・表示幅・スライダー位置は **localStorageに保存**され、リロード後も維持される（地図とテーブルでレイヤー状態を共有）。

### 表ビュー（table.html）
全エンティティを一覧表示。検索（出来事・地域・要約）／時代・分類チップで絞り込み／列見出しクリックでソート（年は数値、時代は時系列順）。種別列とWikipediaリンクつき。

## コンセプトと非目標（スコープ）

historymapは **「点」で世界史の "いつ・どこ" を俯瞰する地図ツール** に徹する。深掘りはWikipediaに委譲する。

**やること（Goals）**
- 時間軸×世界地図で、同時代の出来事を地理的に並べて見せる
- 各エンティティからWikipediaへ橋渡しする（詳細・背景はそちらで読む）
- 世界をなるべく均等にカバーし、地図の「空白＝何も無かった」という誤読を避ける

**やらないこと（Non-Goals）** ※あえて持たない
- **因果・伝播の「繋がり」グラフを自前で持たない** → 関連はWikipediaのリンクをたどってもらう
- **時代ごとの領域・国境（「面」）を自前で持たない** → 版図はWikipediaの各記事に任せる
- 一次史料・学説の網羅や厳密な考証はしない（諸説あるものは代表値を置く）

> 理由：繋がりも国境も、世界が維持しているWikipedia/Wikidataに既にある。個人プロジェクトがそれを抱えるのは保守地獄。
> historymapは「俯瞰と入口」に集中し、深さは外部に委ねることで身軽さと正確さを保つ。

## データ構成

設定・マスタは `config/`、エンティティ（レイヤーの中身）は `data/` に分ける。`index.html` / `table.html` がこれらを読む（取得時にキャッシュバスターを付与し、更新が常に反映される）。

```
config/   設定・マスタ
  layers.json     レイヤー登録表（マニフェスト）
  categories.csv  分類マスタ（コード・名称・色）
  regions.csv     地域マスタ（座標フォールバック用の重心）
data/     エンティティ（レイヤーの中身。すべて同一スキーマ）
  events.csv      出来事 …………… 条約・発明・革命・反乱など、その年の出来事
  wars.csv        戦争 ……………… 戦争・会戦・紛争（古代の会戦〜現代の紛争）
  countries.csv   国・文明 ……… 建国〜滅亡の期間・首都/中心座標
  peoples.csv     民族・部族 …… 拡散的な集団（先史〜古代向け）
  persons.csv     人物 …………… 個人の生〜没
  periods.csv     時代区分 …… 日・中・西欧・印・埃・朝・西アジアの時代の帯
  tech.csv        技術史 ……… 文字・金属・印刷・動力・情報など、技術の登場
  religions.csv   宗教史 ……… 主要宗教の発祥（いつ・どこで）
  leaders.csv     歴代政権 …… 主要国の首相・大統領等の在任期間（G7＋中露印）
```

| エンティティ | 件数 |
|---|---:|
| events / wars / countries / peoples / persons / periods / tech / religions / leaders | 183 / 195 / 107 / 35 / 316 / 79 / 48 / 23 / 334 |（計 1320） |

### レイヤー＝ファイル（同一スキーマ）

`events / countries / peoples / persons / periods` は**すべて同じ列構成**で、いつでもマージ可能。
「種別」は**ファイル名が表す**ので、CSV内に種別列は持たない（DRY）。`layers.json` の登録順がUIとパネルの並び順になる。
ファイルのパスは**リポジトリ基準**でマニフェストに書く（HTMLはそのパスをそのまま取得する）。

```json
{
  "masters": { "categories": "config/categories.csv", "regions": "config/regions.csv" },
  "layers": [
    { "key": "event",  "file": "data/events.csv",    "label": "出来事",     "default": true  },
    { "key": "polity", "file": "data/countries.csv",  "label": "国",         "default": false },
    { "key": "people", "file": "data/peoples.csv",    "label": "民族・部族", "default": false },
    { "key": "person", "file": "data/persons.csv",    "label": "人物",       "default": false },
    { "key": "period", "file": "data/periods.csv",    "label": "時代区分",   "default": false }
  ]
}
```

### エンティティCSVの列設計

| 列 | 型 | 説明 |
|---|---|---|
| `id` | int | ファイル内の連番（一意キー） |
| `year_start` | int | **開始年。BCはマイナス**（BC6500→`-6500`）。ソート・配置はこの列 |
| `year_end` | int/空 | 終了年。点なら`year_start`と同値、スパンは終わり。**空欄＝継続中（存命・現存）**で開始年以降ずっと表示される（`year_label`は「1947〜」のように開いた表記） |
| `year_label` | str | 表示用ラベル（点=`BC660`、スパン=`1603〜1868` / `BC27〜AD476`） |
| `era` | str | 時代区分 `先史/古代/中世/近世/近代/現代`（`year_start`から機械決定。下表） |
| `area_code` | str | 地域コード（`regions.csv`の主キー）。分類・座標フォールバック元 |
| `region` | str | 読みやすい地域名 |
| `category` | str | 分類コード（`categories.csv`） |
| `title` | str | 表示名 |
| `importance` | int | **重要度 1〜5（5が最重要）。人間が編集する列** |
| `summary` | str | 一行要約 |
| `wiki` | str | 日本語Wikipediaの記事名。`https://ja.wikipedia.org/wiki/{wiki}` でリンク（空欄時は`title`） |
| `lat` / `lon` | float | **象徴座標**（戦争=戦地、遷都=都、航海=到達点など）。空欄なら`area_code`の重心にフォールバック |

> `wiki` は全行 MediaWiki API で**実在記事であること（曖昧さ回避ページでないこと）を検証済み**。

## 時代区分（era）の境界

地域で「古代/中世」の感覚がズレるため、**世界史標準の年境界で機械的に統一**（時代の色帯が重ならないように）。`era` 列はこの規則で自動付与する。

| era | 年範囲 | 区切り |
|---|---|---|
| 先史 | 〜 BC1000 | 青銅器文明・文字以前 |
| 古代 | BC1000 〜 475 | 鉄器・古典文明 〜 西ローマ滅亡(476) |
| 中世 | 476 〜 1499 | 〜 大航海時代(1492) |
| 近世 | 1500 〜 1788 | 主権国家 〜 仏革命前 |
| 近代 | 1789 〜 1944 | フランス革命 〜 WW2 |
| 現代 | 1945 〜 | 戦後・冷戦以降 |

> 日本史の学校区分（近世=江戸〜1867、近代=明治〜1945）とは少しズレる。これは世界史横断で揃えるための割り切り。
> なお `periods.csv`（時代区分レイヤー）は各地域固有の区分（縄文・江戸、漢・唐、古王国…）で、この全球`era`とは別物。

## 拡張のしかた

- **行を足す**：該当CSVに1行追加。`id`採番と`year_start`/`year_end`/`lat`/`lon`を入れれば、`era`/`year_label`は揃え直すだけ。
- **レイヤーを足す**：同一スキーマのCSVを`data/`に置き、`config/layers.json`に1行登録するだけ（HTMLはマニフェスト駆動なのでコード変更不要）。例：`data/religions.csv`（宗教の伝播）など。
- **地域を足す**：`config/regions.csv`に`area_code`＋重心緯度経度を追加。
- **分類を足す**：`config/categories.csv`にコード・名称・色を追加。
- **データ品質**：`wiki`列は ja.wikipedia API で実在＆非曖昧を一括検証する運用（記事名ミスや曖昧さ回避ページを弾く）。座標は範囲チェック。

## 設計メモ

- **種別＝ファイル**：種別列を持たずファイル分割。遅延ロードでき、レイヤー追加が1ファイル＋1行で済む。
- **座標フォールバック**：`lat/lon`があればその点に、無ければ`area_code`の重心に描画。広域・全球的な事象は`WORLD`等で地図に出さず（パネルには出る）。
- **キャッシュバスター**：データ取得URLに `?v=<読み込み時刻>` を付与し、データ更新が必ず反映されるようにしている。
- **localStorage**：UI状態（レイヤー/分類/表示幅/年）を永続化。
