# historymap — 標準通史データセット

横軸＝地域（世界地図）/ 縦軸＝年 で世界史の横のつながりを可視化するための素材データ。
「重要度・取捨選択は人間が、要約・抜け漏れチェック・リンクはAIが」という役割分担を前提に設計している。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `timeline.csv` | 出来事（メインデータ） |
| `regions.csv` | 地域マスタ（地図用の緯度経度つき） |
| `categories.csv` | カテゴリ（レイヤー）マスタ |

## timeline.csv の列設計

| 列 | 型 | 説明 |
|---|---|---|
| `id` | int | 連番（一意キー） |
| `year_start` | int | **開始年。BCはマイナス**（BC6500→`-6500`）。ソート・縦軸配置はこの列で行う |
| `year_end` | int | **終了年。点イベントは`year_start`と同値**。戦争・王朝などスパンはここが終わり（タイムライン上で「帯」として描ける） |
| `year_label` | str | 表示用（`BC6500頃` / `前660` / `538(552)` など原典の表記ゆれを保持） |
| `era` | str | 時代区分。`先史/古代/中世/近世/近代/現代`（下記の年境界で機械的に決定） |
| `area_code` | str | 地域コード。`regions.csv` の主キーに対応（**分類・絞り込み・色分けの軸**。座標フォールバック元） |
| `region` | str | 読みやすい地域・国名（その時代の呼称） |
| `category` | str | レイヤー軸。`categories.csv` のコードに対応 |
| `title` | str | 出来事 |
| `importance` | int | **重要度 1〜5（5が最重要）。人間が編集する列** |
| `summary` | str | 一行要約（AIが補完・拡充する想定。空欄可） |
| `wiki` | str | 日本語Wikipediaの記事名。`https://ja.wikipedia.org/wiki/{wiki}` でリンク。全行 実在記事をAPIで検証済み（空欄時は`title`にフォールバック） |
| `lat` | float | **そのトピックを象徴する地点の緯度**（戦争は戦地、遷都は都、航海は到達点など）。空欄なら`area_code`の重心に自動フォールバック |
| `lon` | float | 同・経度。`lat`/`lon`があればマーカーはそこに直接プロットされる |

## 時代区分（era）の境界

地域ごとに「古代」「中世」の感覚がズレるため、**世界史標準の年境界で機械的に統一**している（タイムラインを時代で色帯表示したときに重ならないようにするため）。

| era | 年範囲 | 区切りの出来事 |
|---|---|---|
| 先史 | 〜 BC1000 | 青銅器文明・文字以前 |
| 古代 | BC1000 〜 475 | 鉄器・古典文明 〜 西ローマ滅亡(476) |
| 中世 | 476 〜 1499 | 〜 大航海時代(1492) |
| 近世 | 1500 〜 1788 | 大航海・主権国家 〜 仏革命前 |
| 近代 | 1789 〜 1944 | フランス革命 〜 WW2 |
| 現代 | 1945 〜 | 戦後・冷戦以降 |

> 日本史の学校区分（近世=江戸〜1867、近代=明治〜1945）とは少しズレる。
> 元メモの章立て（1867以降を「現代」に置いていた点）は、この世界史区分に合わせて再配置した。

## 拡張のしかた（行・列を足していく）

- **行を足す**: `id` を採番して1行追加するだけ。`year` さえ入れればソート位置は自動で決まる。
- **地域を足す**: `regions.csv` に `area_code` と緯度経度を追加 → `timeline.csv` から参照。
- **レイヤーを足す**: `categories.csv` にコードを追加（例: `SCI 科学`, `ART 芸術`, `EPI 疫病`）。
  「技術がどう伝播したか」「宗教がどう広がったか」は `category` で絞り込めば見える。
- **別レイヤーの年表**: 同じ列設計で `timeline_tech.csv` 等を並列に持てば、レイヤー切り替えに対応できる。
